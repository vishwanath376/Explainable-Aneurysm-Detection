# Public repository data policy

This repository intentionally excludes raw clinical imaging, patient-level manifests, subject/session identifiers, scanner serials, institution-specific metadata, private dataset tables, derived patient-level predictions, model checkpoints, and redistributed research PDFs.

Only source code, documentation, configuration, and synthetic smoke-test data should be published here. Keep authorized clinical datasets and generated patient-level outputs outside this public Git repository.

Before adding any future artifact, review its provenance, license, privacy status, and redistribution rights.
